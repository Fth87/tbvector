# Form dan validasi

Form demo memakai `Dialog`, `Field`, dan `Input` resmi shadcn-svelte. Label harus terhubung dengan control dan error harus dapat dibaca pengguna.

Validasi demo sengaja minimal karena tidak melewati trust boundary. Saat memakai backend, definisikan schema Zod di feature dan jalankan schema yang sama di Form Action/server sebelum menyimpan data. Validasi client hanya untuk pengalaman pengguna, bukan keamanan.
